# Stick Cat Academy

Professor Whiskers teaches life the way cats see it.

## Content Types

| Type | Description | Frequency |
|------|-------------|-----------|
| **Stick Cat vs Owner** | Daily relatable battles between cat and owner | Daily |
| **Cat Logic** | Professor explains why cats do weird things | 3x/week |
| **Master Cat Life Hack** | Professor teaches life lessons | 2x/week |

## Characters

- **Professor Whiskers** - Wise teacher with glasses and bow tie
- **Luna** - Curious female student
- **Mochi** - Lazy, sleepy male student

## Automation Pipeline

```
Script → AI Images → Voiceover (EdgeTTS) → Video (FFmpeg) → YouTube Upload
```

Runs daily on GitHub Actions. 100% free.

## Tech Stack

- Python 3.11
- EdgeTTS (voiceover)
- Pollinations AI (stick cat images)
- FFmpeg (video assembly)
- GitHub Actions (automation)
